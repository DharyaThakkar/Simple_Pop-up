This is a normal pop-up which we usually see in most of the today's modern website.I have created it using 
using HTML5,CSS and Javascript.In this small mini-project i have used the concepts of "Events" in Js for 
handling the events made by the users and had responded to it.I have created a button and had added a 'click' event listener
to it.so when somebody clicks on the button, immediately a popup will be pop over and the background
will become blur.I have also added the functionality of the removing this popup by adding a close('x') 
anchor tag, and also had added the 'click' event listener to it.so if someone will click on it, they will
be again come back to the normal page and the popup will hide.


Technologies used :- HTML5, CSS, JAVASCRIPT
